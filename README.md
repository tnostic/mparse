# MParse
A lightweight, C++20, header-only library for parsing cli commands. Inspired by getopt & CLI11.

# Quick start & example
To start working with with `mparse`, ensure you have a C++20 compliant compiler. You can build the provided `demo.cpp` file using any of the methods listed below.

## GCC
```bash
# 1. Compiling
g++ -std=C++20 demo.cpp -o mparse_demo
# 2. Run with standard `--help` command
./mparse_demo --help
# 3. With parameters
./mparse_demo -i 50 -b -o
```
